# Variants de direcció

Quatre prototips navegables, d'un sol fitxer, que combinen les dues versions i s'allunyen cada cop més. Tot el contingut és d'exemple.

| Fitxer | Variància | Idea |
|---|---|---|
| `A-placa.html` | Baixa | Fusió: estructura nova, foto real i colors de façana |
| `B-fil-del-dia.html` | Mitjana | Gent gran primer: lletra gran, una cosa cada vegada, lectura en veu alta i micròfon |
| `C-sal.html` | Alta | L'assistent és la interfície: el dia arriba com a conversa amb targetes |
| `D-turo.html` | Màxima | El poble és la interfície: turó generatiu amb la llum de l'hora i marcadors |

Són fragments pensats per publicar-se com a artifact (sense `<html>` ni `<head>`); per obrir-los en local, embolcalla'ls en un document HTML.
