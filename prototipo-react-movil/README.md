# Súria · Guia local

Prototipo móvil en React + TypeScript. Ejecutar `npm install` y después `npm run dev`; abrir la dirección indicada. Para verificar la compilación: `npm run build`. Para ejecutar el resultado compilado con el servicio de guardias: `npm start`.

La farmacia de guardia se consulta en el servidor desde el calendario del Ayuntamiento de Súria. Se usa la hora de Europa/Madrid y el cambio de guardia de las 9:00. El servicio necesita conexión a Internet; si el calendario no cubre la fecha, cambia de formato o no está disponible, no muestra un turno sin verificar. Las respuestas válidas se conservan durante un máximo de cinco minutos. El proyecto necesita un servidor Node que ejecute Vite (o un servicio equivalente que implemente el endpoint); publicar solo `dist/` como archivos estáticos no activa esta función.

Las imágenes son recortes de la referencia suministrada. La búsqueda filtra el contenido mostrado, el selector cambia idioma y el filtro semanal muestra un estado vacío. Los demás detalles son provisionales: faltan datos y destinos reales.

La sección de autobuses selecciona automáticamente el calendario según la fecha de Súria. Los horarios de la Guagua son una transcripción de los carteles municipales; la selección automática solo está habilitada para los periodos y festivos verificados del curso 2026-2027 y hasta agosto de 2027, y los días de libre disposición pueden variar. Fuera de ellos se indica que no es posible determinar el horario. Alsa se consulta desde el GTFS oficial de la Generalitat, usando el calendario y sus excepciones, y se actualiza cada seis horas. Es información programada, no en tiempo real. Si el catálogo falla o no cubre la fecha, se muestra un error. Ambos servicios requieren servidor Node, no solo el directorio `dist/`.

La agenda de la portada consulta la agenda municipal cada cinco minutos y muestra juntas las actividades de los próximos siete días según la hora de Súria, ordenadas por fecha y hora. Las fichas enlazan a sus detalles oficiales; depende de la disponibilidad y el formato de la web municipal. El servidor Node es necesario para esa consulta.

Para revisar las fuentes con la aplicación en marcha, ejecuta `npm run check:sources`. Para comprobarlas continuamente mientras el proceso esté activo, ejecuta `npm run monitor:sources`: registra errores y recuperaciones en la consola y avisa cuando se aproxima el límite de vigencia del calendario de la Guagua. Opcionalmente, `SURIA_BASE_URL` indica la dirección de la aplicación y `SURIA_CHECK_INTERVAL_MS` ajusta el intervalo (mínimo 10 segundos). Es un proceso local: no envía notificaciones ni sigue funcionando si se cierra. Para una vigilancia permanente necesita ejecutarse en un servidor y conectarse a un sistema de alertas.

La búsqueda asistida usa Gemini 2.5 Flash-Lite desde el servidor para reconocer algunas intenciones de búsqueda; solo devuelve categorías y los resultados siguen procediendo de la guía. Para activarla, crea una clave de Gemini y colócala en `GEMINI_API_KEY` dentro de `.env.local` (ver `.env.example`), y reinicia el servidor. No uses `VITE_` ni publiques la clave. El texto de las búsquedas enviadas se transmite a Google; revisa las condiciones de privacidad y uso del proveedor antes de publicar. Sin clave o si falla el servicio, la búsqueda normal sigue funcionando. La protección básica de frecuencia por proceso no sustituye cuotas, autenticación y protección contra abuso al publicar la aplicación.
